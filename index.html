IoT para pivôs centraisIoT for center pivots

TCC · em andamentoThesis · in progress

Sistema para monitorar e acionar remotamente pivôs centrais de irrigação em áreas sem cobertura de rede, usando enlace LoRa entre um nó de campo e um gateway. O nó decide a irrigação localmente e o gateway ajusta o fator de espalhamento conforme a qualidade do canal. A system to remotely monitor and control center-pivot irrigation in areas without network coverage, using a LoRa link between a field node and a gateway. The node decides irrigation locally and the gateway tunes the spreading factor to channel quality.

  • Comando só é confirmado quando o nó informa o estado real dos relésA command is confirmed only after the node reports the actual relay state
  • Ciclo de trabalho para reduzir consumo e filtro de sinal contra acionamentos falsosDuty cycling to cut power use and signal filtering against false triggers
  • Acionamento por botão local, painel web e assistente de vozControl from a local button, a web panel and a voice assistant
